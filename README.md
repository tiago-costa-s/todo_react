## Descrição

Esta é uma aplicação de lista de tarefas (todo list) que permite aos usuários adicionar, editar e remover tarefas. A interface é simples e intuitiva, facilitando o gerenciamento de tarefas diárias.

## Instalação

Para executar este projeto localmente, siga estas etapas:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu_usuario/todo-list.git
   cd todo-list

Uso
Para usar a aplicação de lista de tarefas:

Abra o navegador e vá para http://localhost:3000.
Adicione uma nova tarefa no campo de entrada e pressione "Enter" ou clique no botão de adicionar.
Marque as tarefas como concluídas clicando na caixa de seleção ao lado de cada tarefa.
Edite ou remova tarefas usando os botões de editar e excluir.
